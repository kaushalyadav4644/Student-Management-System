A lightweight, browser-based Student Management System built with HTML, CSS, and JavaScript. It allows users to dynamically add student records, search students by roll number, view department marks, and instantly identify class toppers.

🌐 **Live Demo:** [kaushalyadav4644.github.io/Student-Management-System/](https://kaushalyadav4644.github.io/Student-Management-System/)

---

## 🚀 Key Features

* **Add Student Records:** Input student name, roll number, department, and marks dynamically.
* **Search Functionality:** Quickly look up specific student records by entering their roll number.
* **Topper Highlight:** Easily find and display the top-performing student in the system with a single click.
* **Live Record Table:** Clear, organized data table showing all registered students at a glance.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (DOM Manipulation)
* **Hosting:** GitHub Pages ([Live App](https://kaushalyadav4644.github.io/Student-Management-System/))
